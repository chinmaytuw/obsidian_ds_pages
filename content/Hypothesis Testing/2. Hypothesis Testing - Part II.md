# **Right-Tailed, Left-Tailed, and Two-Tailed Tests**

- Assume we are trying to estimate the mean height of 18 year olds and we take 10 random samples.

- We need to make sure the data quality is representative, randomized, and the sample size is big enough.

![[image 33.png|image.png]]

  

- Now, our sample mean i.e. observation is 68.44. The agreed claim is that mean is 66.7.

- In this case, the null hypothesis H0 is that mean height has not changed whereas the alternative is that it has increased.

![[image 1 9.png|image 1.png]]

  

- Now, there are 3 types of hypothesis depending on how where we propose the observed statistic is relative to null hypothesis value.
    
    - The right tail test is when H0 = 66.7 and H1 > 66.7 i.e. to the right of H0.
    
    - The left tail test is when H0 = 66.7 and H1 < 66.7 i.e. to the left of H0.
    
    - The two tail test is when H0 = 66.7 and H1 ≠ 66.7 i.e. to the either sides of H0.
    

![[image 2 9.png|image 2.png]]

  

## Type 1 and Type 2 errors in context of right tailed test (left tailed will be similar)

- #Type_1_error  will be false positive i.e. that claiming $\mu$ changed when in fact it did not.

- #Type_2_error  will be false negative i.e. Claiming that $\mu$ did not change when in fact it did.

# p value
#p_value

- In this case we will look at right tail test. Type 1 error here is determining that the population mean has increased from 66.7 whereas in fact, it hasn’t.

- We will use the sample mean and see how probable is it to observe this value. **The goal is that the probability of Type 1 error should be less than 5% to reject the null hypothesis**.

- This probability is the area under the curve i.e. probability of observing a value of 68.442 or more. In this case it is 0.03 which is lower than our threshold of 0.05 so we can reject null hypothesis.

## After notes on Z statistic:

### 2 Different #z_statistic.

- The above in valid for  One-Sample #z_test. This tests if a **single sample mean** differs from a known population mean μ. Used when:
    
    - ==$z= \frac{\bar{x} - \mu}{\sigma/\sqrt{n}}$==
    - You have one group
    - Testing against a known/hypothesized value
    - You know the population standard deviation σ
    

- In our typical use case i.e. #AB_testing. Suppose we are trying to compare heuristic vs ML model performance, we will use Two-Proportion #z_test 
    
    - $z = \frac{\hat{p}1 - \hat{p}2}{\sqrt{\hat{p}{pooled}(1-\hat{p}{pooled})(\frac{1}{n_1} + \frac{1}{n_2})}}$
        - Here, $\hat{p}_{pooled} = \frac{x_1 + x_2}{n_1 + n_2}$
            - ==x being # of purchases and n being # of observations. So suppose we are measuring heuristic vs ML model performance. Say x1 is associated with heuristic model, x1 would represent purchases for that model and n being number of people it was exposed to. Similar for x2, only that we can think of it as ML model.==
    
    - This tests if **two sample proportions** differ from each other. Used for AB testing when:
        - You have two independent groups
        - Comparing them to **each other** (not to a fixed value)
        - Binary outcomes (conversion: yes/no)

- **Conceptually, they're the same structure:**
    $z = \frac{\text{observed difference} - \text{expected difference}}{\text{standard error of the difference}}$

### **For one-sample:**

- Numerator: $$\bar{x} - \mu$$ (how far is sample mean from hypothesized mean?)

- Denominator: $$\sigma/\sqrt{n}$$ (standard error of the mean)

### **For AB testing (two-proportion):**

- Numerator: $$\hat{p}{ML} - \hat{p}{heuristic} - 0$$ (difference in proportions; under H₀ the expected difference is 0)

- Denominator: pooled standard error (accounts for variance in **both** groups)

### SE for Z statistics:

- In the two-proportion #z_test , the #standard_error  measures: **"If we repeated this experiment many times with different random samples, how much would the difference in conversion rates** $(\hat{p}_1 - \hat{p}_2 )$ **vary from experiment to experiment?"**

#### The Intuition:

- **Small SE** → The difference we observe is **precise**. If we ran the test again, we'd likely get a very similar difference. High confidence in our estimate.

- **Large SE** → The difference we observe is **noisy**. If we ran the test again, the difference could vary a lot. Low confidence in our estimate.

### Why This Matters for the Z-Statistic

- The #z_statistic  is:

$$z= \frac{\text{observed difference}}{\text{SE of difference}}$$

This is a **signal-to-noise ratio**:

- **Numerator** (signal): How big is the effect we observed?
- **Denominator** (noise): How much random variability should we expect?

**If SE is small** → Even a small observed difference can be statistically significant (high z-value)
**If SE is large** → You need a large observed difference to overcome the noise (low z-value)

- You can find a more concrete example in [this](https://claude.ai/share/b57fc65e-058e-4a81-a8d3-623cc4767683) chat with Claude
- Think of SE as noise. The precision of your estimate. Lower SE means more precision and confidence.

# Critical value

- For any known distribution and significance level, we can calculate the value beyond which we can reject null hypothesis. We don’t even need the sample observed statistic to calc this threshold. This is the critical value.

- For example, for the below distribution, and significance level of 0.05, the critical value will be 68.26. Any value greater than this would mean we can reject the null hypothesis.
